# 密钥与敏感信息说明

## 结论

**本仓库没有任何属于开发者或用户的凭据。** 全历史扫描（gitleaks 6 个 commit + 自写熵检测器）
未发现 API Key、Token、私钥、密码等真实凭据。

GitGuardian 报出的命中项，是**目标平台（超星学习通）的公开协议常量**，属于误报。
下面逐条说明。

## 被命中的两处常量

### 1. `internal/consts/consts.go` → `AESKey = "u2oh6Vu^HWe4_AES"`

- **它是什么**：超星登录接口 `passport2.chaoxing.com/fanyalogin` 用于加密账号/密码的
  AES-128-CBC 密钥。
- **为什么不是泄露**：这个密钥**硬编码在超星自己的登录页前端 JavaScript 里**，
  任何人打开登录页、按 F12 就能看到。它不是我们的服务端密钥，也不是用户的凭据 ——
  它是客户端必须与服务端约定的对称密钥。
- **上游同样存在**：原项目 [Samueli924/chaoxing](https://github.com/Samueli924/chaoxing)
  的 `api/config.py` 中同样是明文 `AESKey = "u2oh6Vu^HWe4_AES"`，该仓库 3.7k star、公开可访问。
- **不能删除**：删掉或"轮换"它，登录功能立刻失效。

### 2. `internal/consts/consts.go` → `VideoEncSalt = "d_yHJ!$pdA~5"`

- **它是什么**：超星视频/音频进度上报接口 `enc` 参数的 md5 拼接盐值。
- **为什么不是泄露**：同上，硬编码在超星播放器前端 JS 中；上游
  `api/base.py: Chaoxing.get_enc` 同样明文存在。
- **不能删除**：删掉后所有视频任务点的进度上报都会被服务端拒绝。

## 为什么会被扫描器报出来

GitGuardian / gitleaks 的 "Generic High Entropy Secret" 规则只看**字符串本身的熵与字符构成**：

| 值 | 长度 | 香农熵 | 大小写混合 | 含符号 |
| --- | --- | --- | --- | --- |
| `u2oh6Vu^HWe4_AES` | 16 | 3.88 | ✅ | ✅ |
| `d_yHJ!$pdA~5` | 12 | 3.46 | ✅ | ✅ |

这类规则没有"这是平台协议常量"的语义判断，所以会对任何看起来像密钥的高熵字面量报警。
这正是本项目保留 `.gitleaks.toml` 与 `.gitguardian.yaml` 加白名单的原因 ——
**加白是有据可查的，不是掩盖**。

## 已做的处理

1. **收敛重复字面量**：原先密钥/盐值在 `consts.go`、`crypto.go`、`crypto_test.go`、
   `docs/接口契约.md` 里各写了一遍。现在只有 `internal/consts/consts.go` 一处定义，
   其余位置全部引用常量，文档改为指向定义处。字面量出现次数从 6 处降到 1 处。
2. **原地加溯源注释**：在定义处写明"这是目标平台的公开协议常量、上游同样明文存在、
   扫描器会误报、移除会破坏功能"。
3. **扫描器加白**：`.gitleaks.toml` + `.gitguardian.yaml`，附上述理由。
4. **提供自查脚本**：`scripts/scan_secrets.py`，可随时复跑。

## 自查方法

```bash
# 官方扫描器（全历史）
gitleaks git --no-banner .

# 本仓库自带的熵检测器（复刻 GitGuardian 的通用规则）
python3 scripts/scan_secrets.py .
```

## 用户需要注意的真实风险

代码本身不泄露任何东西，但**运行时数据**是敏感的，请勿提交：

- `~/.chaoxing-go/accounts.json` —— 账号与加密后的密码
- `~/.chaoxing-go/key.bin` —— 本机加密密钥
- `~/.chaoxing-go/cookies_*.txt` —— 各账号会话 cookies
- `config.ini` —— 若填写了题库 token / 大模型 API Key / 通知服务 URL

这些路径均已在 `.gitignore` 中排除。
